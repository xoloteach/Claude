# IRONLINE audio credits

All files in `assets/audio/sfx/` are generated by `tools/audio/gen_sfx.py`
(`python3 tools/audio/gen_sfx.py`), which downloads the source recordings below and
layers/processes them with numpy/scipy synthesis (sub thumps, transients, synthetic
slap-back impulse responses, saturation, compression). Every source is **CC0 / public
domain**; attribution is given as a courtesy.

| Source | Author | License | Used for |
